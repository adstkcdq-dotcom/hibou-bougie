## Confidentialité de l'app (App Privacy)
Données collectées par le SDK Google AdMob, utilisées pour la publicité, l'analyse et la prévention des fraudes :
- Identifiants › Identifiant de l'appareil (IDFA, seulement si l'utilisateur accepte le suivi) — lié au suivi : oui
- Données d'utilisation › Interactions avec le produit, Données publicitaires
- Diagnostics › Données de plantage, Données de performances
- Localisation › Position approximative (déduite de l'IP)
Aucune donnée liée à l'identité (pas de compte). Suivi (tracking) : oui, via AdMob, avec la fenêtre ATT.

## Classification par âge
Aucun contenu sensible → 4+. Publicités : oui. Pas de communication entre utilisateurs, pas de jeux d'argent, pas d'accès web libre.

## Notes pour l'examen d'Apple (règle 4.2)
Hibou & Bougie is a complete offline game built with Capacitor: native local notifications at the end of the focus timer, native StoreKit review prompt, native share sheet, AdMob rewarded ads with ATT, and all content is bundled in the app (no remote website). No login required.
